Deep dive · consumer

The consumer contract in 14 lines

@KafkaListener(topics = "orders.v1")
void onOrder(OrderPlaced evt, Acknowledgment ack) {
  if (dedupe.seen(evt.eventId()))
    { ack.acknowledge(); return; }

  // idempotent on eventId
  store.upsert(evt.orderId(), PLACED);
  metrics.lag(evt.ts());
  dedupe.mark(evt.eventId());
  ack.acknowledge();
}
// retries → parking topic → alert
@Bean DefaultErrorHandler errors() {
  return new DefaultErrorHandler(park, backoff); }
  • Dedupe firstReplays are free and expected
  • Idempotent upsertSame event twice = same state
  • Errors are policy, not codeOne handler, shared by every consumer
What changes for teams

From owning a batch window to owning an event

Today · nightly batch
  • Status refreshed once a day
  • Every new use case edits the batch job
  • Failures found the next morning
Target · event-driven
  • Status in under 2 seconds
  • New consumers subscribe, nothing upstream changes
  • Failures parked, alerted and replayable
